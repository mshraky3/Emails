Email Automation Service

This service runs scheduled email automations (age reminder, gold advisory, GitHub streak, job digest, and application follow-up).

  • /api/health
  • /api/test-email
  • /api/cron/dispatch-daily-reminder
  • /api/cron/monitor-gold-price
  • /api/cron/check-github-streak
  • /api/cron/send-job-digest
  • /api/cron/check-applications

Note: cron endpoints may return 401 Unauthorized if CRON_SECRET is enabled and request headers are missing.

If CRON_SECRET is enabled, call /api/test-email?key=YOUR_CRON_SECRET for manual browser testing.
