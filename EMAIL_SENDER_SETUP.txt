This guide will help you create a new Node.js application that can send emails. Follow these steps to set up your project and start sending emails using a popular package like Nodemailer.

---

## 1. Prerequisites
- Node.js and npm installed (https://nodejs.org/)
- An email account (Gmail, Outlook, or any SMTP provider)

---

## 2. Project Initialization
1. Create a new directory for your app:
   ```bash
   mkdir email-sender-app
   cd email-sender-app
   ```
2. Initialize a new Node.js project:
   ```bash
   npm init -y
   ```

---

## 3. Install Dependencies
- Install Nodemailer:
  ```bash
  npm install nodemailer
  ```

---

## 4. Create the Email Sender Script
- Create a file named `sendEmail.js`:
  ```js
  const nodemailer = require('nodemailer');

  // Configure your SMTP transport
  const transporter = nodemailer.createTransport({
    service: 'gmail', // or another provider
    auth: {
      user: 'your-email@gmail.com',
      pass: 'your-app-password' // Use an app password if 2FA is enabled
    }
  });

  // Email options
  const mailOptions = {
    from: 'your-email@gmail.com',
    to: 'recipient@example.com',
    subject: 'Test Email',
    text: 'Hello from Node.js!'
  };

  // Send email
  transporter.sendMail(mailOptions, (error, info) => {
    if (error) {
      return console.log(error);
    }
    console.log('Email sent: ' + info.response);
  });
  ```
- Replace `your-email@gmail.com` and `your-app-password` with your credentials.
- For Gmail, you may need to create an App Password: https://myaccount.google.com/apppasswords

---

## 5. Run the Script
```bash
node sendEmail.js
```

---

## 6. Security Tips
- Never commit your real credentials to version control.
- Use environment variables or a `.env` file for sensitive data (see the `dotenv` package).
